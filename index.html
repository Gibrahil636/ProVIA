ProVIA
Laboratório de Imagens · Módulo 1

Gere lotes de imagens em vários motores de IA, com proveniência registrada (qual motor, qual prompt, quando). As chaves e as imagens ficam somente no seu navegador — este site não tem servidor e não guarda nada de ninguém.

1

Conectar os motores de IA

Cole a chave de API dos motores que você tem. Cada chave é sua, gratuita ou pré-paga, e é enviada apenas para a própria empresa do motor — nunca para este site.

Google Geminigrátis

Crie uma chave gratuita em aistudio.google.com/apikey (conta Google, sem cartão). Há uma cota diária de imagens.

como criar a chave (1 minuto)
  1. Abra o link acima e entre com sua conta Google.
  2. Clique em Create API key e depois em Copy.
  3. Volte aqui, cole no campo abaixo e aperte testar chave.
OpenAI (GPT Image)opcional

Chave em platform.openai.com/api-keys. Contas novas podem receber crédito de boas-vindas; depois, cada imagem custa centavos de dólar (modelo econômico).

como criar a chave (1 minuto)
  1. Abra o link acima, entre (ou crie conta) e clique em Create new secret key.
  2. Copie a chave inteira (começa com sk-) — ela só aparece uma vez.
  3. Cole abaixo e aperte testar chave.
Avançado · OpenRouter (uma chave para vários modelos)
OpenRouterbeta

Chave em openrouter.ai/keys (uso de imagem é pago, em centavos). Escolha o modelo abaixo — a lista vem do catálogo público do OpenRouter.

Meta AIassistido · sem API

A Meta não oferece API de imagens — nenhum site do mundo consegue gerar nela por você. No modo assistido, cada imagem vira um cartão com o prompt pronto: copiar → colar no meta.ai → baixar → devolver no cartão. Uns 40 segundos por imagem.

Copilot (Microsoft)assistido · sem API

O produto Copilot não expõe API. Modo assistido igual ao da Meta (copilot.microsoft.com) — ou use o motor MAI-Image, da própria Microsoft, automaticamente via OpenRouter acima.

Privacidade: este site é estático (GitHub Pages), sem servidor próprio. Chaves e imagens existem apenas no seu navegador; nada é coletado.

Transparência: no nível gratuito do Gemini, o Google pode usar o conteúdo enviado para aprimorar seus modelos, e as imagens saem com marca-d'água invisível SynthID. Na OpenAI, o modelo econômico custa a partir de ~US$ 0,005 por imagem.
